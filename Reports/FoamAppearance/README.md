# 泡沫表现优化实施记录 · 2026-09-18

**状态：功能已实现；未通过综合验收。** 地形提交 P95 仍超过 2 ms，GPU、新增表现完整 CPU/GC 预算及移动端尚未取得有效设备证据。此报告不将同步测试通过等同于性能或真实多设备验收通过。

## 实现

- 三个固定种子圆顶权重 60% / 25% / 15%，按原笔刷合法连通采样面积归一化；新落点后最多两轮守恒圆顶整理，再执行原四轮坡度整理。
- 保持 0.25 m 采样、4 m 分块、20 Hz 提交，毫米提交高度由画面、碰撞与支撑共用。体积预算、敌方消融、限高、分层和防包埋链路保留。
- 512² 可平铺泡孔数据纹理、Mipmap、不透明三平面着色、柔和高光、距离法线衰减；独立 `FoamAppearance.asset` 保存美术与反馈配置，重烘焙地图保留配置。
- 已安装变化的本地反馈：节点阈值 1 cm、每块 100 ms、24 组 × 8 颗上限、寿命 ≤0.45 s、8/16 m 距离分级。池满丢弃；恢复、历史追赶和清空不播放。不增加网络消息。
- 邻块法线刷新与真实几何刷新分开，法线刷新不重建碰撞；归属只在阵营变化时上传。CPU 原地图归属直接读取三角形权重。
- 每次提交/安装保存阶段计时。游戏模拟签名 14 → 15，网络差量和检查点格式不变。Luban、武器伤害/射速/墨量未修改。

## 性能结论与门槛

编辑器固定输入全部活动提交的 P95（各阶段独立取百分位，不能相加）：总计 3.5682 ms，分配 0.5016、圆顶整理 0.4380、坡度整理 0.8460、归属 0.2603、网格 0.5959、碰撞 0.3675、反馈通知 0.0521 ms。计时不含截图，也不包括全部角色/弹道查询、网络发送和外部角色占用准备。

- **地形提交 ≤2 ms：未达标。** 同机八进程含资源争用，也不应以争用为由宣称目标达成。
- **新增表现 CPU P95 ≤0.3 ms：未验收。** 通知回调 0.0521 ms 不包含粒子系统全部原生模拟/渲染提交；圆顶整理也有额外成本。
- **新增 GPU P95 ≤0.5 ms：无有效证据。** 旧/新非 batch 隐藏 Player 都 `renderedFrames=0`、`gpuTimingAvailable=false`；`run_render_probe.py` 均返回失败。对应目录为 `baseline-render-hidden/` 和 `current-render-hidden/`。这些输出不能算 GPU 或正常帧率数据。
- **GC：局部提交热路径测试通过；全表现链路零持续 GC 未验收。** 网络诊断/整帧报告本身有分配，不能声称全游戏零 GC。
- **移动端：未验收。** 尚无指定手机；60 FPS 只是预算档位。真实有画面双机/八机也未验收。

后续按原优先级先缩减泡粒或细节显示距离来控制表现成本；本轮无渲染测试已经超出地形预算，单纯减少粒子无法解决模拟/碰撞热点。不得延迟碰撞安装来达标。

## 重跑与构建

正式构建入口 `PrototypeBuilder.BuildWindowsTo`，构建原因：独立进程网络及 Player 性能验证。输出 `Builds/Windows-FoamAppearance-20260918/InkLan.exe`；`build-status.txt` 为 PASS，`build-manifest.json` 记录文件 SHA256。342 个运行时文件，共 284883883 bytes（不含 DoNotShip）。最后追加的测试及编辑器包装器保存恢复修正不改变此包运行时代码。PlayerSettings 的临时计时与预加载资源变更已恢复。

1. 固定输入：写 `Temp/FoamAppearance/label`，再按 `Docs/FoamTerrain.md` 的测试请求入口执行 `Splatoon.Tests.FoamAppearancePlayTests`。核心类为 `Splatoon.Tests.FoamTerrainTests`，真实地图类为 `Splatoon.Tests.FoamTerrainPlayTests`。
2. 纹理：`python Tools/FoamTerrain/bake_pores.py`；Unity 菜单“喷墨对战 → 表现 → 构建绵软泡沫资源”。
3. 对照：`python Tools/FoamTerrain/compare_appearance.py --baseline Reports/FoamAppearance/baseline --current Reports/FoamAppearance/final --output Reports/FoamAppearance/comparison-final`。
4. 联机：`python Tools/FoamTerrain/run_acceptance.py --exe Builds/Windows-FoamAppearance-20260918/InkLan.exe --output Reports/FoamAppearance/network-repeat --matrix smoke`；矩阵选项另有 `eight-late`、`reconnect`、`reset`、`full`。
5. 隐藏 Player 渲染探针：`python Tools/FoamTerrain/run_render_probe.py --exe Builds/Windows-FoamAppearance-20260918/InkLan.exe --output Reports/FoamAppearance/render-repeat`。操作者需要显示交互窗口时显式加 `--visible`。只有 `renderedFrames>0` 才作为有效渲染运行；GPU 字段仍需独立判断可用性。
