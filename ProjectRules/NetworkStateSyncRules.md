# 网络状态同步规范

- NGO 房主负责权威玩法状态、伤害、命中结果、随机值和比赛阶段。
- 客户端以 60Hz 采样输入、30Hz 批量发送；本地角色预测运动与资源，按房主确认输入序号纠正并重放，远端角色插值显示权威快照。
- 同步稳定标识和模拟帧号，禁止同步 Unity InstanceID 或 ScriptableObject 引用。
- 特效、音效和相机反馈仅影响表现，不能修改权威状态。
- 生命周期 Revision 只用于初次绑定、重生或明确失效；普通纠正不得重新绑定动画。初始或恢复墨迹同步完成前暂停本地预测；完成后以已应用权威墨迹继续预测，不因全图墨迹序号落后而冻结移动，依赖补齐时按最新权威快照重放。输入超时丢弃旧输入并等待新回执。
- 客户端历史重放只更新模拟状态与移动胶囊，弦化轮廓和命中代理在最终呈现状态确定后更新；房主在权威弹丸检测前更新命中几何。
- HUD 游戏往返时间以每秒两次的不可靠回显及客户端单调时钟测量，包含两端帧调度；三秒无有效回复显示无有效测量。房主标注本机裁决，不以固定零毫秒代替公平性说明。
- 专用服务器、历史位置回滚命中和匹配服务作为后续扩展；本地预测不授予客户端伤害、涂墨或计分权限。

- 每名玩家同步 WeaponId 与独立 EquipmentRevision。可靠换枪请求在房主模拟边界验证身份、阶段、回合、生命周期与开发权限；装备修订不触发生命周期重置。旧装备输入只能重放移动，不得按新枪参数开火。
- 松开射击与取消攻击是不同输入：UI、失焦、输入超时或换枪不得触发蓄力释放。墨弹保存发射时的武器和蓄力程度，不能依赖射手当前装备。

- 沿途落墨半径由房主按每颗墨弹的独立随机状态逐次生成，实际半径随墨迹同步；客户端与补入房间使用相同权威半径。
- 热身换队请求在房主模拟边界检查身份、回合、生命周期和四人队伍容量；与换英雄互斥，成功后以一个新生命周期快照切换队伍并重生。旧输入不能跨生命周期使用。
- 半自动支持点击单发及长按按冷却连续发射。首发起手、点击缓存与持续长按状态由预测和权威模拟共同维护；强制中断必须等待松键，不能当作蓄力释放或继续旧连发。
- 玩家 K/D/A 使用独立网络快照，由房主按实际扣血与受害者生命周期统计；助攻取死亡前 5 秒内（含边界）的有效敌对伤害贡献，按攻击者去重。房主玩家 ID 0 有效，缺少攻击者使用可空身份表示。普通重生保留战绩，断线和新回合清除对应记录。
- 正式开局同步权威 StartsAt 和回合标识；提示按服务器时间窗口播放，表现层不得暂停计时或阻断操作。开局仅允许热身且双方各有人，每队容量为 4。
- 结算返回热身只能由房主执行，推进回合同步代次，清空墨迹、弹丸与战绩并重生，保留连接、队伍和英雄。重置、涂墨和弹丸消息必须检查代次，拒绝上一阶段的迟到消息；结算不能直接再次开局。
- 用户名仅在入房前大厅修改并保存本机；入房载荷携带协议、内容签名及用户名，由房主校验后写入独立的服务端可写网络变量，不进入高频移动快照。重生、换队、换英雄和返回热身保留名字，断线清理连接元数据；重名不影响玩家 ID 和战绩归属。头顶名隐藏自己、死亡、纸片形态及场景遮挡目标，Tab 仍显示所有玩家用户名。
