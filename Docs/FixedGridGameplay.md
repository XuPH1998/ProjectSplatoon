# 固定网格积木玩法（2026-10-18）

本文件记录本次获批玩法与生产入口。实现、Editor 回归、正式包与正式验收分别记录；历史 surfacepaint58 和物理原型的结果不代表本版本通过。

## 规则

- 全局网格边长 0.30 米，16³ 区块，维持地图范围与 8 米世界顶界。
- 每个当地地图支撑面最多 4 层，露出不超过 1.2 米。桥面、桥下与楼层各自使用真实地图支撑基准；已有积木不会重置高度基准。
- 固定格具有连续的实体占据，阻挡角色和弹道，可站立。己方固定格可恢复、弦化、爬墙。没有推动、旋转、逐帧落块或自由块运动同步。
- 空白地图命中涂色，敌色直接替色，己色生成固定格；己格命中沿面形成圆盘候选；敌格只拆；原拆毁型爆炸只拆。
- 无下方紧贴支撑的候选直接投到正下方第一个支撑，不能穿桥。固定块支撑不区分阵营，墙面色格不提供垂直支撑。
- 地图落点按空白、敌色、己色重新分类。完整色格不合法、超高、重复、禁建、越界、玩家占据等拒绝候选并退回未用攻击额度。
- 抽底在同一事务按旧高度从低到高重排局部列。保持稳定块 handle；转色或删除立即失效。移动和转换不再次消耗材料或授予生成／拆敌充能。

## 生产路径

- `PrototypeMatch.EnsureBlocks` 使用 `EnableFixedGridMode`；旧 `EnableSurfaceMode` 仅留历史测试与物理实现。
- `BlockFixedGridWorld` 维护稳定身份、格索引、水平列索引和提交版本，真实占据存储复用 `BlockWorld`。
- `BlockFixedGridTransaction` 私有暂存建造、拆除、涂色和受影响列整理。提交前完成角色安全预演；失败保留旧提交。同步提交固定格与独立 `BlockSurfaceWorld`。
- `BlockTerrain.FixedGrid` 适配真实地图、禁建、玩家、局部显示更新与即时攻击结算。按 XZ 列缓存地图所有支撑层；地图适配器改变几何后显式调用 `NotifyFixedMapSupportChanged`。
- `BlockFixedGridQueries` 提供数据 Cast、Overlap、Support 等查询。命中不要求存在 Collider，角色读取已提交数据，显示网格不作为碰撞发布门。
- 显示复用合面网格，后台构建受影响区块，仅上传完成的显示结果；不创建逐格 GameObject、Rigidbody 或 BoxCollider。
- `BlockFixedGridCodec` / `PrototypeMatch.FixedGridSync` 配对传输格与涂色，完整准备后统一安装、再确认；取消生产自由块运动包。迟加入使用完整快照。
- 玩法／内容协议版本升级。生产固定模式拒绝旧 World 与动态物理载荷，不迁移历史世界。
