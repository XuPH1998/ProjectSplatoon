# 静态墨迹升级

目标是主体浅薄、外缘圆润隆起的湿墨层：保留边缘厚度感、笔触对应的浅起伏、可过滤的细法线和环境反射。正式训练场使用新外观，粉/青配色、原始 32 款覆盖轮廓、武器涂色、归属、计分及移动判定保持原数据链路。

## 数据与渲染

- `InkAppearanceProfile` 从 Resources 加载一次，统一绑定细节图集、细法线和以米为单位的外观参数。细节图集是原有 8×4、每格 256×256 布局；R 为高度，G 为粗糙度变化。编辑器按原始轮廓重心和主方向、固定种子生成，不修改覆盖图集。
- `PaintSurface` 在原有笔触绘制中使用两个 MRT 输出：原覆盖 RGBA 与新视觉 RG。视觉数据按覆盖预乘、有界混合并量化为字节，反复涂色不会无限堆高。停止涂色后停止更新。默认 RG8，不支持时用 RGBA8；快照始终为 RG 两字节格式。
- 相同尺寸和格式共享临时纹理。MRT 显式绑定目标自身的无深度附件，并设置完整纹理视口，避免窗口尺寸限制较大的墨迹纹理。显示颜色和细节补边使用同一整数像素邻居选择规则，避免 UV 岛接缝的颜色/细节错配和重复过滤漂移。地面拼接和坡道折叠沿用原始笔触派发。
- Shader 保持原始可见覆盖阈值，另从合并覆盖的世界尺度邻域以有限差分重建圆润边坡；持久高度、极弱大尺度变化和可 mip 的细法线形成三个尺度。数值队伍 ID 只用 point sample 解码后比较，异色交界可产生浅槽及粗糙度变化。新外观关闭自发光闪点，DepthNormals 与 Forward 使用相同的新法线计算。
- 默认边缘表观高度 0.018、过渡宽度 0.055（米制着色参数），内部浅起伏 0.002。边缘使用光照法线表现厚度，不抬高实际网格；同色合并后只保留整体外缘，斜坡/墙面共用同一算法。
- 覆盖与持久视觉纹理均无 mip，避免跨岛/跨队伍混色；只给可平铺细法线使用 mip、三线性与各向异性过滤。细法线按像素覆盖淡出，并根据法线变化降低光滑度。Android 分支去掉队伍浅槽、大尺度噪声和局部反射探针。
- 三只 128 分辨率静态探针在未涂色地图烘焙，分别覆盖中央及两侧。烘焙时临时添加 ReflectionProbeStatic 标记，结束还原原标记；不改变场景太阳、环境光、曝光、Bloom。

## 同步与兼容

`PaintCheckpoint.VisualSurfaces` 与 `Surfaces` 必须按 SurfaceId 成对。主线程在同一序号边界复制两张 GPU 纹理，再异步读回；任何面失败都不发布检查点。解码会验证版本、拓扑、尺寸、ID 配对及尾部数据，再清空旧状态。恢复两张纹理、重放补同步日志并刷新显示后，才设置 InitialSyncComplete。

快照版本 6，PaintProtocol 11；原 PaintStamp 网络结构未扩充，WeaponSimulation 19 保留。内容签名增加细节图集实际 RG 数据哈希与累计算法版本。切换外观只影响显示，两张数据面始终累计，避免切换导致联机状态不同。

Luban 源表 `TbGlobal.xlsx` 仅修改 `maxPaintMemoryMiB=256`、`snapshotBytesPerSecond=1048576`；生成器产生运行时 JSON。保留 4096 字节分块、8 块/帧、8 条在途、512 笔检查点。

## 使用与回退

Unity 菜单 `喷墨对战 > 墨迹静态表现`：

1. **生成并应用**：确定性生成细节资源、绑定正式材质、烘焙三只探针。执行前保存场景并退出 Play Mode。
2. **切换旧外观 / 切换新外观**：本地对比着色及探针，保留同一套网络状态。

完整源码回退使用 `Tools/InkStaticUpgrade/restore.ps1`。默认仅核对清单，传 `-Apply` 才恢复。它先检查所有当前文件及基线的 SHA256；任何文件出现后续改动就停止，避免覆盖其他工作。只恢复清单中的修改，并逐个删除本次新增资源及 `.meta`。清单和基线保存在本次本机报告目录，不是版本库通用卸载程序。

## 验证与证据

最新运行结果、图片、视频、原始 XML/JSON/日志记录在 `Reports/InkStaticUpgrade/README.md`。报告明确区分编辑器/GPU/主相机实测、同机多进程、物理双机和用户视觉验收；构建成功不能代替这些验收。

复现命令见 `Tools/InkStaticUpgrade/validate.ps1`、`run_player_validation.py`、`run_network_validation.py`。请使用独立项目副本，避免影响正在打开的正式编辑器。Player 性能脚本观察正常主相机，密集涂色完成后 10 秒预热、60 秒采样；视频捕获连续主相机帧，视频录制开销不计入性能结果。
