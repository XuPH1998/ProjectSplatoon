# 大招与自由配装

## 操作与配置

- H 打开英雄、副武器、大招统一选择；主武器仍由英雄决定。13 种副武器与 5 种大招通过独立 Luban 目录列出。
- 热身可换装，比赛只允许本方出生区；倒地、死亡、结算、正在使用大招时禁止。Host 校验整套选择，实际变更提升配装修订号并清空能量/旧持续实体；同套重复确认不重置。
- 每名英雄的最近搭配使用本地 PlayerPrefs 保存；首次默认原副武器＋终极发射；普通复活保留选择。初次同步后按当前阶段从热身或本方出生区恢复保存搭配；结算、忙碌或暂不满足换装条件时延后重试，以实际快照确认成功。
- Q 满能量启动并补满墨槽。左键：终极发射射击；投掷型按住瞄准、松开投出；鲨鱼允许制动后按左键提前引爆。E 保持副武器。
- 默认 200 点；TbSpecialWeapon.requiredPoints 是按大招覆盖；TbLoadoutCost 以0代表通配，指定字段最多的组合规则优先，最高优先级重叠视为错误。
- 配置来源为 Config/Luban/source 的 TbSubWeapon、TbSpecialWeapon、TbLoadoutCost；通过 gen_luban.bat 生成。不要修改 Generated 或生成 JSON。
- 五个 SpecialWeaponConfigAsset 位于 Assets/GameResource/SpecialWeapons，每个有简模、图标与占位音效；全部目录参与 Addressables 和内容签名。

## 运行与同步

Host 对实际计分地面网格的新归属面积记账；墙面、无来源环境涂墨、己方已有格子、击杀和自然时间不直接计分。玩家0是合法来源。重叠笔刷若补满新的边缘格子，只累计这些新格子。涂地点数面积系数仍为待原版固定区域校准的推算值，详见参数表。

充能/手持状态/场上实体寿命独立。声呐从投出锁定，底座被破坏提前解锁但已有波保留；墨雨从雨云激活锁定8秒且跨复活保留。倒地冻结未用能量，最终死亡减半；已启动手持/骑乘中断不返还。

协议版本36，玩法签名32。输入携带Q边沿；旧配装输入不改变当前Q基线，生命周期或配装修订变化时本地Q序号对齐权威确认值；快照携带英雄、副武器、大招、修订号、能量、阶段、权威时间及骑乘状态。生命周期事件可靠传输，周期完整实体快照用于补偿与晚加入；实体保留出生时的不可变配置。客户端不结算伤害和涂地收益。预测表现只在新输入执行时触发，不在纠正重放中生成。

## 复刻边界

这是一版可运行的实现，**尚不满足所有原版细节已经逐项验收的声明**。原始字段覆盖、已使用的实测数据、原生默认值缺口和当前项目近似值均列于 [参数核对表](SpecialWeaponParameters.md)。200点是项目确认默认，不是原作任意组合平衡值。

声呐水平环与墨雨线是简化表现；没有完整原版动画和音效。原始数据中不存在的默认值没有被冒充为已提取数据。必须继续验证原版固定面积计分、墨雨降雨空间采样/跨层、鲨鱼爆炸外围涂墨/击退及部分弹道继承行为。

## 验证入口

Unity 菜单“喷墨对战/大招/安装五种大招和自由配装目录”安装资源。SpecialWeaponTests 检查核心逻辑、原始字段映射及序列化；SpecialWeaponPlayTests 进入 Boot 启动本地 Host，检查真实场景地面归属、部署物状态及表现快照，并验证屋顶遮挡与重叠雨云伤害去重。

独立进程验收：先生成开发包，再运行 `python Tools/specialweapon_network_acceptance.py --scenarios 0 200`。该脚本只操作自己的测试进程，并通过UDP代理模拟延迟/抖动/丢包；运行参数 `-specialRole` 才会启用游戏内验收驱动。测试结果记录在 Reports/SpecialWeapons，编辑器结果与独立进程/真实双机LAN结果分别报告。

独立进程 Q 缓存专项：追加 `--input-cache-probe`。先完成常规五大招及回合重置，再由探针在客户端本地序号中构造未发送的按键，验证真实复活快照、配装 RPC 后的序号重置与后续新 Q。该模式验证本地缓存与网络链路，不声称覆盖操作系统真实键盘事件。测试临时更改的本地配装偏好会在正常／报告失败退出时恢复。

验收范围更新：真实双机LAN由用户自行执行，不属于代理完整复刻验收的完成条件。原作参数还原要求不变，机制／数值缺口继续作为代理需要处理的事项；编辑器与同机独立进程证据仍分别记录。

生命恢复采用原作者逐帧实测估计：普通0.21 HP/帧（12.6 HP/秒），潜墨与友方墨雨1.75 HP/帧（105 HP/秒），受伤等待60帧。它替换早期项目30/60 HP/秒默认值；来源年份、每秒标注矛盾及11.3.0原生值仍待确认的限制见参数核对表。

鲨鱼空中按Q进入等待落地阶段，能量保持、禁止充能且不无敌；实际地面接触后才开始准备计时和能量消耗。等待期间倒地按项目规则中断耗尽。HUD区分等待落地、准备冲刺、冲刺、制动蓄爆与恢复。

鲨鱼在菜单、失焦或旧配装输入中断后，需要先松开左键再重新按下才接受提前制动；自动制动和已开始的蓄爆仍按时执行。

用户最新验收范围：数值类回归不再执行或作为放行门槛，参数仍尽量按原作配置并标注来源。保留功能、输入、配装、实体生命周期及同机独立进程联机同步验证；真实双机由用户自行验证。

墨雨发生器的共享投掷碰撞包含部署物受击体与起点重叠，预览、预测和房主接触结果使用同一路径；不会将玩家受击代理当作该部署物查询的对象。

大招有效受击后的存活目标可产生碰撞约束击退，终极发射空中发射带反冲；外力状态参与权威快照和预测重放，并在复活/中断时清理。参数来源及近似解释见参数表。

最终状态：按用户调整后的功能验收范围已完成（玩法签名32／协议36）。数值类回归、真实双机及实际菜单/焦点输入回归按要求排除；参数近似说明仍保留，不宣称原作数值逐项精确一致。最终证据位于 Reports/SpecialWeapons/ParityFixes/final-functional-acceptance.md。
