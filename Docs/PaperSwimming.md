# 实时纸片潜墨

所有存活的潜墨与紧凑状态使用人形纸片。墙面按实际接触点进入，允许友方颜色及无色，拒绝敌方颜色；地面资格、资源恢复、武器和跳跃数值由原模拟控制。平面地面、墙面和共面接缝可用，不支持自动绕直角、曲面贴附或滑翔。

## 资源配置

Unity 菜单 **喷墨对战 → 内容 → 配置实时纸片潜墨** 从五个角色的 Visual Prefab 生成专用 `PaperCapture.prefab`，保留模型、材质、Avatar 和 Animator Controller，按对应武器 Prefab 组装持枪挂点，移除玩法脚本、粒子和碰撞体。生成结果位于 `Assets/GameResource/Characters/Shared/Paper/`。

`CharacterPresentationProfile.Paper` 引用各角色的 `PaperBodyProfile`。其中配置拍摄 Prefab、透明 RenderTexture 分辨率（默认 512×1024）、固定取景范围、显示尺寸、表面偏移、厚度和相机支点。取景范围由实际运行时动画采样器测量。修改源模型、骨架或动画后，应重新运行配置菜单，更新拍摄 Prefab、取景和内容签名。无需导出人物 PNG 或固定姿势动画。

## 运行流程

`PaperCapture` 为每名进入潜墨的角色创建独立子场景、骨架和禁用自动渲染的摄像机。`PaperAnimation` 使用原有 Animator Controller 的持枪待机和各方向持枪移动动作，保留源动作、武器对齐和左手握点 IK。动画进度和方向从快照显式求值，播放速度采用原角色移动动画参考速度。每个动画秒最多采样 30 个帧；同一份骨骼变形和武器网格生成画面及受击轮廓。

透明画面通过 URP 单摄像机渲染请求写入该玩家自己的 RenderTexture；不写入地图墨水，也不读取磁盘 PNG。角色模型和灯光仅在拍摄请求期间可见，结束后立即禁用。隐藏的人物本体 Animator 不参与纸片拍摄。更换角色、禁用和销毁时释放子场景、网格、原生缓存和 RenderTexture。

受击轮廓由 Burst 将同一姿态的三角形（含随姿态移动的武器）投影到 64×128 网格，再合并成保留肢体空隙的薄体，默认厚度 0.04 米。`CharacterController` 负责通行和运动阻挡，纸片网格负责受击。纸片网格和备用受击胶囊使用第 10 层 `PlayerHitProxy`，该层与所有层关闭物理接触；运动、地面墨水、攀墙及相机查询统一排除第 8、10 层。第 8 层角色运动胶囊之间的碰撞保持开启。枪弹查询包含受击层，并保留墨弹半径和墙体遮挡。完全嵌入薄体的小球用同一轮廓的解析距离补充查询。细小发丝和透明材质可能存在栅格近似误差，不是逐像素命中或骨骼伤害映射。

运行顺序为运动模拟、`PaperPoseSimulation` 计算地面/墙面/空中/翻越姿态、动画采样与受击体更新。纸片外框、武器及透明边缘不参与通行资格，不要求整片有支撑；纸片允许越出墙沿或平台边缘。真实障碍由运动胶囊阻挡并处理滑动，不再因纸片支撑或矩形扫掠失败回滚位置、清零速度。所有空中纸片统一保持水平；显示纠正只平滑位置，不移动权威受击体。墙面纸片头部朝上，镜头转动不改变其贴墙朝向。

入墙继续使用配置中的 0.6 米探测距离，实际接触点必须为可攀墙面上的己方颜色或无色。己方墙面使用 WallSwimSpeed（当前 4 米/秒），无色墙面使用 NeutralSwimSpeed（当前 3 米/秒），敌方颜色立即脱墙。胶囊先执行吸附移动，抵达后才以实际位置和接触点提交墙面状态。向下贴墙遇到地面碰撞后，走统一的友方/无墨/敌方地面资格判断。翻越使用原有向上 1 米、向墙内 0.6 米的探测，仍检查胶囊路径和站立空间；纸片高度不再扩大翻越距离。

## 空中形态切换

跳跃、下落和蹬墙跳期间可使用原潜墨按键反复进入或退出。空中新进入潜墨时，纸片在角色根位置上方半个纸片高度处水平展开，长轴采用进入当帧的逻辑 Yaw，忽略俯仰；持续潜墨时保持该平面并随位移移动。已经潜墨的角色从地面、斜坡离地或跳离墙面时，同样转换为水平平面；再次贴墙后恢复贴墙姿态。

`AirSwimSource` 独立于当前形态保存本次腾空来源：友方墨水潜墨起跳及友方墙面离开使用当前 SwimSpeed（8 米/秒）；无墨潜墨起跳、无色墙面离开、常规形态起跳和无来源的空中进入使用 NeutralSwimSpeed（3 米/秒）。切回常规时按原常规/开火参数运动，再次潜墨恢复同一来源；切换不清零速度或增加跳跃推力，水平速度依原加速度调整，重力保持不变。落地、死亡、复活和换角清空腾空来源；落地后重新按实际地面墨水判断。

恢复常规形态仍检查完整胶囊空间；不足时保持紧凑纸片并沿用开火限制，空间充足后自动恢复。空中潜墨不享受友方墨水的额外回血回墨，常规恢复及其冷却、开火优先级保持原有规则。空中新进入潜墨后仍可按原接触条件吸附己方墙面。

## 联网与验证

`PlayerSnapshot` 协议版本为 15，包含纸片平面、中心、姿态切换时间、动画进度、移动方向及腾空来源 `AirSwimSource`。房主结算伤害；本地预测和纠正重放使用同一运动及姿态计算。网络内容签名中的纸片算法版本为 6，包括拍摄资源摘要、取景参数、纸片尺寸、世界查询掩码、受击层编号及碰撞矩阵；不再包含支撑采样点。新旧移动规则不能混用。

Editor 测试 `PaperBodyTests` 覆盖实时画面变化、轮廓与画面对齐、重放、独立实例、正背面与侧面命中、肢体空隙、墨弹半径、墙体遮挡，以及穿过独立受击体时的胶囊轨迹。`PaperTraversalTests` 使用实际玩家 Prefab 和纸片配置，覆盖五角色远距离连续入墙、上下左右与斜向移动、镜头旋转、下墙后的三类地面、纸片越出墙沿、障碍滑动和预测重放，并对比自身受击体开关前后的轨迹。

Edit Mode 直接调用 `SwimBody` 的测试必须显式释放拍摄资源后再销毁玩家，不能依赖普通 MonoBehaviour 在编辑模式下执行生命周期回调。测试清理调用现有资源释放方法，防止离屏预览场景耗尽编辑器的场景剔除掩码；游戏内的渲染及生命周期保持原有实现。

`SwimPlayTests` 从 Boot 通过 Addressables 启动真实 NGO 房主，覆盖五个角色、两队、伤害和生命周期，并在实际 TrainingGround 从墙外 2.5 米处执行友方/无墨地面、正向/斜向共 20 组连续入墙、攀爬、下墙、跳离或翻越。输入由测试驱动生产 `Simulate`，每组入口帧数及攀爬距离记录于 `Reports/PaperBody/PlayMode/natural-traversal.txt`。验证截图与测量输出位于 `Reports/PaperBody/`；它们不是运行时资源。这些测试不代替人工操作观感、独立客户端、物理双机、发布包及 GPU 帧耗验收。

空中测试覆盖腾空来源和速度连续性、序列化及重放、五角色水平展开和再次定向、蹬墙跳切换、空中墙面资格、低矮空间及换角清理。真实房主在 TrainingGround 验证五角色的常规/无墨/友方起跳和走下平台后的反复切换，以及空中开火后重新潜墨，结果写入 `Reports/PaperBody/PlayMode/air-switching.txt`。
