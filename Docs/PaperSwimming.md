# 实时纸片弦化

所有存活的弦化与紧凑状态使用人形纸片。当前 [积木玩法](BlockGameplay.md) 的地面与墙面附着只允许稳定己方积木；中立地图、敌方积木和下落积木不提供附着资格。支撑被拆除或开始下落后，下一次移动模拟退出附着；空中形态切换和翻越保留，不增加天花板附着。连续积木可拟合局部坡面，拟合不跨越空洞，真实碰撞仍遵循积木形状。不支持自动绕直角、曲面贴附或滑翔。

## 资源配置

Unity 菜单 **喷墨对战 → 内容 → 配置实时纸片潜墨** 从工具已配置角色的 Visual Prefab 生成专用 `PaperCapture.prefab`，保留模型、材质、Avatar 和 Animator Controller，按对应武器 Prefab 组装持枪挂点，移除玩法脚本、粒子和碰撞体。生成结果位于 `Assets/GameResource/Characters/Shared/Paper/`。新增角色时需沿现有角色配置链路补齐纸片资源，不能把早期五角色测试结果直接转记到新增角色。

`CharacterPresentationProfile.Paper` 引用各角色的 `PaperBodyProfile`。其中配置拍摄 Prefab、透明 RenderTexture 分辨率（默认 512×1024）、固定取景范围、显示尺寸、表面偏移、厚度和相机支点。取景范围由实际运行时动画采样器测量。修改源模型、骨架或动画后，应重新运行配置菜单，更新拍摄 Prefab、取景和内容签名。无需导出人物 PNG 或固定姿势动画。

## 运行流程

`PaperCapture` 为每名进入弦化的角色创建独立子场景、骨架和禁用自动渲染的摄像机。`PaperAnimation` 使用原有 Animator Controller 的持枪待机和各方向持枪移动动作，保留源动作、武器对齐和左手握点 IK。动画进度和方向从快照显式求值，播放速度采用原角色移动动画参考速度。每个动画秒最多采样 30 个帧；同一份骨骼变形和武器网格生成画面及受击轮廓。

透明画面通过 URP 单摄像机渲染请求写入该玩家自己的 RenderTexture；不写入地图墨水，也不读取磁盘 PNG。角色模型和灯光仅在拍摄请求期间可见，结束后立即禁用。隐藏的人物本体 Animator 不参与纸片拍摄。更换角色、禁用和销毁时释放子场景、网格、原生缓存和 RenderTexture。

受击轮廓由 Burst 将同一姿态的三角形（含随姿态移动的武器）投影到 64×128 网格，再合并成保留肢体空隙的薄体，默认厚度 0.04 米。`CharacterController` 负责通行和运动阻挡，纸片网格负责受击。纸片网格和备用受击胶囊使用第 10 层 `PlayerHitProxy`，该层与所有层关闭物理接触；运动、地面接触、攀墙及相机查询统一排除第 8、10 层。第 8 层角色运动胶囊之间的碰撞保持开启。枪弹查询包含受击层，并保留弹丸半径和墙体遮挡。完全嵌入薄体的小球用同一轮廓的解析距离补充查询。细小发丝和透明材质可能存在栅格近似误差，不是逐像素命中或骨骼伤害映射。

运行顺序为运动模拟、`PaperPoseSimulation` 计算地面/墙面/空中/翻越姿态、动画采样与受击体更新。纸片外框、武器及透明边缘不参与通行资格，不要求整片有支撑；纸片允许越出墙沿或平台边缘。真实障碍由运动胶囊阻挡并处理滑动，不再因纸片支撑或矩形扫掠失败回滚位置、清零速度。所有空中纸片统一保持水平；显示纠正只平滑位置，不移动权威受击体。墙面纸片头部朝上，镜头转动不改变其贴墙朝向。

地面弦化从脚下稳定己方积木的连续邻格拟合朝向，统一驱动移动方向、纸片姿态和受击体。拟合遇到断开的支撑即停止，不把空洞补成平面；纸片可以超出边缘不等于空洞能够承托运动胶囊。显示和受击体使用同一模拟姿态，局部坡面不会替换真实积木碰撞。

入墙继续使用角色配置中的探测距离，当前为 0.6 米；实际接触点必须为稳定己方积木的可攀侧面。己方墙面使用 `WallSwimSpeed`，当前为 4 米/秒；中立墙面不再按旧 `NeutralSwimSpeed` 提供附着。胶囊先执行吸附移动，抵达后才以实际位置和接触点提交墙面状态。墙面消失、变为敌方或开始下落时退出附着；向下贴墙遇到地面后重新判断稳定己方积木资格。翻越使用原有向上 1 米、向墙内 0.6 米的探测，仍检查胶囊路径、目标地形和站立空间；纸片高度不扩大翻越距离。

## 空中形态切换

跳跃、下落和蹬墙跳期间可使用弦化按键反复进入或退出。空中新进入弦化时，纸片在角色根位置上方半个纸片高度处水平展开，长轴采用进入当帧的逻辑 Yaw，忽略俯仰；持续弦化时保持该平面并随位移移动。已经弦化的角色从地面、斜坡离地或跳离墙面时，同样转换为水平平面；再次接触稳定己方积木墙面后恢复贴墙姿态。

`AirSwimSource` 独立于当前形态保存本次腾空来源：稳定己方积木弦化起跳或离墙保留友方来源，常规起跳及无来源的空中进入使用中立来源。空中弦化速度、重力与下落参数走角色配置的 `AirSwimSpeed`、`AirSwimGravity`、`AirSwimFallSpeed` 等字段，不能套用旧地面或中立墙面速度；当前角色表的 `AirSwimSpeed` 为 6 米/秒。切回常规时按常规/开火参数运动，再次弦化保留同次腾空来源；切换不增加跳跃推力，速度按当前空中模拟调整。落地、死亡、复活和换角清理腾空来源；落地后重新按实际稳定积木接触判断附着资格。

恢复常规形态仍检查完整胶囊空间；不足时保持紧凑纸片并沿用开火限制，空间充足后自动恢复。空中弦化不享受稳定己方积木接触提供的额外回血与快速材料恢复，普通恢复及其冷却、开火优先级保持原有规则。空中新进入弦化后仍可按当前接触条件吸附稳定己方积木墙面。

## 联网

当前源码的 `PlayerSnapshot` 协议版本为 37，包含纸片平面、中心、姿态切换时间、动画进度、移动方向、腾空来源 `AirSwimSource`，以及支撑格 `SupportCell`、所需区块版本 `SupportTerrainRevision` 和地面朝向 `GroundNormal`。房主结算伤害；本地预测和纠正重放使用同一运动及姿态计算，地形依赖未就绪时等待安装相应版本再重放。积木协议为 3；网络内容签名中的纸片算法标识仍为 6，并包含拍摄资源摘要、取景参数、纸片尺寸、世界查询掩码、受击层编号及碰撞矩阵等。新旧移动规则不能混用；源码常量不单独证明某个发布包已完成握手或移动验收。

## 历史纸片验证记录

下列测试说明、角色数量、旧表面分类及报告路径保留自早期纸片版本，不表示当前九把主武器对应角色、动态积木坡面或候选 Windows 包已经通过。旧说明中的玩家协议 15、己方/中立起跳 8/3 米每秒和中立墙面可附着均为历史参数或规则；现行积木资格与空中配置以上文为准。当前积木验证进展见 [首版状态](../Reports/BlockTerrain/FirstPlayableStatus20261013.md)。

Editor 测试 `PaperBodyTests` 覆盖实时画面变化、轮廓与画面对齐、重放、独立实例、正背面与侧面命中、肢体空隙、墨弹半径、墙体遮挡，以及穿过独立受击体时的胶囊轨迹。`PaperTraversalTests` 使用实际玩家 Prefab 和纸片配置，覆盖五角色远距离连续入墙、上下左右与斜向移动、镜头旋转、下墙后的三类地面、纸片越出墙沿、障碍滑动和预测重放，并对比自身受击体开关前后的轨迹。

Edit Mode 直接调用 `SwimBody` 的测试必须显式释放拍摄资源后再销毁玩家，不能依赖普通 MonoBehaviour 在编辑模式下执行生命周期回调。测试清理调用现有资源释放方法，防止离屏预览场景耗尽编辑器的场景剔除掩码；游戏内的渲染及生命周期保持原有实现。

`SwimPlayTests` 从 Boot 通过 Addressables 启动真实 NGO 房主，覆盖五个角色、两队、伤害和生命周期，并在实际 TrainingGround 从墙外 2.5 米处执行友方/无墨地面、正向/斜向共 20 组连续入墙、攀爬、下墙、跳离或翻越。输入由测试驱动生产 `Simulate`，每组入口帧数及攀爬距离记录于 `Reports/PaperBody/PlayMode/natural-traversal.txt`。验证截图与测量输出位于 `Reports/PaperBody/`；它们不是运行时资源。这些测试不代替人工操作观感、独立客户端、物理双机、发布包及 GPU 帧耗验收。

空中测试覆盖腾空来源和速度连续性、序列化及重放、五角色水平展开和再次定向、蹬墙跳切换、空中墙面资格、低矮空间及换角清理。真实房主在 TrainingGround 验证五角色的常规/无墨/友方起跳和走下平台后的反复切换，以及空中开火后重新潜墨，结果写入 `Reports/PaperBody/PlayMode/air-switching.txt`。
