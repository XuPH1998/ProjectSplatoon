# 局域网喷射原型

## 开始游戏

当前射击与墙游版本优先从 Unity Boot 场景验证，Addressables Play Mode 选择 Use Asset Database。已有发布目录不代表已包含本次修改；正式重新构建后，再将整个 `Builds/Windows` 文件夹复制到另一台电脑运行 `InkLan.exe`。

1. 房主选择自己的局域网 IPv4 地址（可点击切换网卡），保留默认 UDP 7777，点击 **创建房间并生成房间码**。
2. 进入场地后按 Esc，点击 **复制房间码**，按钮短暂显示“已复制”。将房间码发给伙伴。
3. 伙伴在主菜单的房间码输入框填写或点击 **粘贴**，再点击 **加入房间**。不需要另填 IP 和端口。
4. 同机双程序测试：房主选择 `127.0.0.1` 后创建，或在房间菜单中切换分享地址为 `127.0.0.1`。双机测试必须选择实际局域网地址。
5. 至少两人到齐后，房主按回车开始三分钟对局；结算后点击 **再来一局**。
6. Esc 打开菜单，可继续游戏、复制房间码或退出房间。窗口失去焦点后会释放鼠标，回来按 Esc 或点 **继续游戏**。

房间码包含 IPv4 和端口，是可校验的地址快捷方式。同一地址和端口生成相同码；重新建房地址端口不变时，旧码仍指向该地址的新房间。输入码错误会提示校验失败；码正确但房主已离线会连接失败或在 20 秒后超时。房主多网卡时可在菜单中切换分享地址并重新复制。**高级：使用 IPv4 地址直接连接** 保留手动直连入口，使用上方端口字段。

Windows 防火墙首次询问时，允许程序在专用网络通信。两台机器应连接同一局域网；访客 Wi-Fi 的客户端隔离可能阻止直连。端口占用时换一个端口，两端填写一致。

## 操作与规则

| 操作 | 按键 |
| --- | --- |
| 移动 / 视角 | WASD / 鼠标 |
| 跳跃 / 射击 | 空格 / 鼠标左键 |
| 在己方墨水里潜墨、加速、快速回墨 | 按住左 Shift |
| 己方墨墙攀游 / 墙顶翻越 | Shift + W 接墙；W/S 上下、A/D 横移；净空允许时自动翻越 |
| 脱墙 / 向外跳离 | 松开 Shift / 空格；开火先脱墙，净空不足时暂缓 |
| 热身枪械列表 | H；点击枪名预览参数，再点击装备 |
| 菜单 / 释放鼠标 | Esc |
| 开发调试换枪 | 编辑器或 Development Build：Esc 后点击左上角 DEBUG，再选择换枪 |
| 开局（房主，至少两人） | Enter |

粉蓝两队自动平衡分配，最多 4 人。正式开局会清空热身涂色并重置角色。底层地面、高台、坡道和桥面可以反复覆盖并独立潜墨，桥上桥下互不影响；内部高台、掩体的竖直墨墙可以攀游；外圈、栏杆和桥底禁止攀游，墙面和掩体新增查询区域不增加比分面积。比分按各层实际可涂地面面积统计，坡道使用斜面面积，分母为全部有效可涂地面面积，因此双方比例之和可能不足 100%。

五把枪共用 RifleGirl 和现有枪械模型，各玩家独立选择。标准、轻型速射、重型、三连发、蓄力狙击均由 Luban 配置；三连发长按连续打组，蓄力狙击按住蓄力、松开发射。列表展示伤害、射击节奏、墨耗、射程、散布及移动速度，与当前装备比较。

热身换到另一把枪补满墨量；对局只允许编辑器或开发环境的 DEBUG 换枪，墨量保持不变。换枪不改变生命、位置或重生保护，取消旧枪连发／蓄力，并保留冷却和回墨锁定。重生和下一回合保留装备，退出／重连恢复默认标准枪。窗口不会暂停比赛；打开界面、失焦和输入超时会取消攻击，关闭界面后松开鼠标再射击。

100 生命、100 墨量，无友伤。标准射击枪每 6F 发射一颗（参考 60Hz，即 10 发/秒）；人形起手 2F，出墨起手 10F。每发耗墨 0.92，满墨可发射 108 发；近距伤害 36，飞行 8–40F 内线性降至 18。最后一发后锁定回墨 20F，普通/潜墨恢复 10/35 点每秒。

移动/射击/地面潜墨/墙游速度为 5/3.6/8/4 米每秒。地面与空中散布半角为 5°/12°。受伤后等待 1 秒，普通/己方潜墨恢复 30/60HP 每秒。敌墨移速倍率 0.55，每秒扣 20HP，最低扣至 60HP且禁止回血，低于 60HP 不会被环境规则抬高。击倒后 3 秒重生，2 秒保护，开火提前解除保护。时间配置保留参考帧，其他项目初值来自 Luban。

允许中途加入，补齐当前涂色、角色及剩余时间。结束后加入则显示结算。房主离开会结束房间，客户端回到主菜单。本地角色预测移动、身体转向和墨量，房主确认后重放未确认输入；伤害、涂墨和计分仍由房主裁定。不包含房主迁移、联网匹配或历史位置回滚命中。

## 编辑器与构建

- Unity 6000.3.9f1；直接打开正式 Boot 场景。人物、枪械、动画和表面资源已正式落地。
- 唯一构建入口仍是 Boot，玩法资源通过本地 Addressables 加载。
- 修改 Config/Luban/source 下角色、武器、房间模式、场地或全局源表后运行 `cmd /c Config\Luban\gen_luban.bat`。禁止手改生成 C#/JSON。
- “喷墨对战/构建/Windows 正式资源版本”只构建现有正式资源，不重新生成地图或人物。
- NGO + Unity Transport，60Hz 玩法模拟/输入采样、30Hz 输入批发/快照和 120Hz 弹道子步。玩家协议 7、墨水快照协议 5。Luban 配置、地图拓扑、角色碰撞体、逻辑枪口、相机几何及转身曲线参与连接签名，不一致时拒绝连接。
- 各可行走表面的局部归属网格为 0.125 米，场地为 X 宽 32 米、Z 长 64 米。地面、墙壁与掩体的纹理通过检查点及有序事件补齐，中途加入等待初始同步完成。

## 验证清单

`Docs/LAN-Validation.md` 是早期版本的验证记录，不能作为射击与墙游版本的验收结果。本次使用隔离编辑器工程执行测试，正式 Addressables、发布包与真实双机结果单独记录。

- 同机双进程：独立角色和相机、移动跳跃、射击命中、地面覆盖一致、潜墨回墨、击倒重生、完整 180 秒结算、再次开局。
- 边界场景：错误 IP、端口占用、连接取消、超时、满员、内容不一致、中途加入补同步、退出再加入、房主退出及重复建房。
- 两台实体电脑：客户端通过房主真实 IPv4 地址加入；双方交叉观察角色、涂色、击倒与比分。此项不能由同机测试替代。

开发版诊断参数：`-lanSmokeHost` 或 `-lanSmokeClient`，可搭配 `-lanAddress 127.0.0.1 -lanPort 7788 -logFile <绝对日志路径>`。`-lanLeaveAfter 8 -lanCycles 2` 可测试同一进程两轮退出重进；`-lanCancelAfter 1` 测试连接取消。这些参数启用独立于真实键鼠的集成测试驱动，正常游戏请不要添加。日志中的 `[SMOKE]` 包含比赛阶段、格数及涂色校验值，用于比较两个进程。图形模式还会生成不含 HUD 的场景离屏截图。

房间码诊断：客户端添加 `-lanRoomCode <房间码>` 时，使用与中文界面相同的解码及连接入口；此参数与 `-lanSmokeClient` 配合。中文化范围、字体及工程配置见 `Docs/Project-Configuration.md`。
