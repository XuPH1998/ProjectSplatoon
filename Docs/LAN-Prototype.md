# 局域网积木对战原型

## 开始游戏

当前默认玩法为 [积木建造与拆毁](BlockGameplay.md)。从 Unity Boot 场景运行时，Addressables Play Mode 选择 Use Asset Database。已有发布目录不代表包含当前源码；Windows 包以 [首版状态](../Reports/BlockTerrain/FirstPlayableStatus20261013.md) 中记录的实际输出与验证结果为准，分发时复制该包的整个目录并运行 `InkLan.exe`。

1. 房主选择自己的局域网 IPv4 地址（可点击切换网卡），保留默认游戏 UDP 7777，点击 **创建房间**。
2. 伙伴在局外的 **局域网房间** 列表中找到房间，点击 **加入**。列表显示房间标识、模式、地图、当前/最大人数、探测延迟和比赛状态，每 2 秒自动刷新；也可点击 **刷新列表**。
3. 未发现时，房主进入场地后按 Esc，点击 **复制房间码** 发给伙伴。伙伴填写或粘贴后点击 **使用房间码加入**；也可在高级入口输入 IPv4，使用上方游戏端口直接加入。
4. 同机双程序测试：房主选择 `127.0.0.1` 后创建，或在房间菜单中切换分享地址为 `127.0.0.1`。双机测试必须选择实际局域网地址。
5. 双方各至少一人后，房主按回车开始三分钟对局，全员显示“游戏开始！”及短音效；结算后由房主点击 **返回房间**，全员回热身，再由房主开局。
6. Esc 打开菜单，可继续游戏、复制房间码或退出房间。窗口失去焦点后会释放鼠标，回来按 Esc 或点 **继续游戏**。

房间码包含 IPv4 和端口，是可校验的地址快捷方式。同一地址和端口生成相同码；重新建房地址端口不变时，旧码仍指向该地址的新房间。输入码错误会提示校验失败；码正确但房主已离线会连接失败或在 20 秒后超时。房主多网卡时可在菜单中切换分享地址并重新复制。**高级：使用 IPv4 地址直接连接** 保留手动直连入口，使用上方端口字段。

Windows 防火墙首次询问时，允许程序在专用网络通信。两台机器应连接同一局域网；访客 Wi-Fi 的客户端隔离可能阻止直连。端口占用时换一个端口，两端填写一致。

## 操作与规则

| 操作 | 按键 |
| --- | --- |
| 移动 / 视角 | WASD / 鼠标 |
| 跳跃 / 射击 | 空格 / 鼠标左键 |
| 在稳定己方积木上弦化、加速、快速恢复材料 | 按住左 Shift |
| 己方积木墙面攀游 / 墙顶翻越 | Shift + W 接墙；W/S 上下、A/D 横移；净空允许时自动翻越 |
| 脱墙 / 向外跳离 | 松开 Shift / 空格；开火先脱墙，净空不足时暂缓 |
| 副武器 / 大招 | E / Q；具体瞄准与释放方式随装备变化 |
| 换装列表（热身 / 对局己方换装区） | H；选择主武器、副武器和大招，再确认装备 |
| 菜单 / 释放鼠标 | Esc |
| 开发调试换枪 | 编辑器或 Development Build：Esc 后点击左上角 DEBUG，再选择换枪 |
| 开局（房主，至少两人） | Enter |

加入时按人数分配粉蓝两队，每队最多 4 人、房间最多 8 人；热身可主动换队，开局要求双方各至少一人，允许 2v1 等不满员对局。正式开局会清空热身积木并重置角色。三分钟结束时，己方存活积木数量更多的一队获胜，相同为平局。已经形成的下落积木也计分；坍塌和重新落定不改变数量，飞行弹丸与装饰碎片不计分。

积木边长 0.10 米，建造沿用地图水平边界，全局顶界为世界坐标Y＝8米。普通枪命中地图生成首层，命中己方积木向命中面外侧堆积，命中敌方积木则拆敌并结束本次命中。每个新格按实际地图墙面位置判断首层锚固，突出部分需要下方支撑；失去支撑后向下掉落。已有稳定、非锚固堆叠每0.25秒开始一轮守恒摊开，逐格形成下宽上窄的阶梯坡；每列每轮最多搬出一块，过载时顺延处理。出生和换装保护区的完整竖直列禁止生成积木。桥上桥下按真实积木空间和碰撞分别通行，不使用旧平面面积计分。空白地图地面和合法墙面允许3米／秒中立弦化及爬墙，只提供普通回能；己方稳定积木保留加速与快速回能。

当前主武器共九把：斯普拉射击枪、开尔文 525、爆炸泼桶、窄域标记枪、快速爆破枪、斯普拉旋转枪、满溢泡泡枪、专业模型枪 MG、爆泡霰弹枪。爆炸泼桶、快速爆破枪和爆泡霰弹枪只拆除，不建造。全部十三种副武器和五种大招沿各自配置接入；结构爆破的敌方半径采用攻击配置，己方半径为其 50%，静态地图遮挡爆破，角色伤害独立结算。每次实际扣费建立共享攻击预算，多弹丸、反弹、沿途与脚下效果不重复获得额度；持续部署物使用部署时获得的有限预算。救援事件不免费生成或拆除积木。

热身更换主武器对应的英雄时补满材料，仅调整副武器或大招不额外补满。对局中可以回到己方换装区域按 H 换装，材料不因换装补满；大招使用中或结算阶段不能换装，开发环境的 DEBUG 入口同样受比赛阶段和换装区域校验。换装取消旧攻击、清空大招充能与旧部署物，并保留已有的冷却及材料恢复锁定。重生和下一回合保留装备；确认成功的副武器与大招组合按英雄保存本机，重新进入后等待同步与合法换装时机恢复。窗口不会暂停比赛；打开界面、失焦和输入超时会取消攻击，关闭界面后松开鼠标再射击。

角色当前为 100 生命、100 材料，无玩家友伤。稳定己方积木允许地面与墙面弦化，并提供加速与快速回能；空白地图地面和合法墙面允许中立弦化及爬墙，速度 3 米／秒、普通回能 10 点／秒。敌方积木不提供弦化资格，下落积木不承托角色；己方积木支撑被拆除或开始下落后，下一次移动模拟重新查询接触，背后仍有合法地图墙时转为中立附着，否则退出附着。连续积木的局部坡面驱动弦化朝向、纸片姿态和受击体，拟合不跨越空洞，真实碰撞仍为积木形状。空中形态与翻越保留，具体行为见 [纸片弦化](PaperSwimming.md)。

稳定己方积木上的弦化提供快速材料恢复；普通恢复、射后恢复锁定、移动和武器数值以当前角色表与武器 Asset 为准。敌方积木不施加旧墨迹规则的持续掉血或移速倍率。大招按实际建造和拆敌结果充能，每 32 格获得 1 点，主攻击整组最多 2 点、副武器整次使用最多 10 点；拆己方、重力移动、救援和大招自身不充能。

允许中途加入，补齐当前积木、角色及剩余时间。结束后加入则显示结算。房主离开会结束房间，客户端回到主菜单。本地角色预测移动、身体转向和材料，房主确认后重放未确认输入；伤害、积木变化和计分由房主裁定。角色快照记录支撑格及所需地形版本，依赖补齐后再重放相关移动。不包含房主迁移、联网匹配或历史位置回滚命中。

## 编辑器与构建

- 房间发现使用独立 UDP **47777**，不能用作游戏端口。发现范围为可用 IPv4 网卡的广播可达子网，支持同机回环；不跨 VLAN、不依赖互联网。房主启动完成后才被发现，停止响应 6 秒后从列表移除。
- 列表中的“探测延迟”是加入前 UDP 查询往返时间；局内显示 Unity Transport 的“连接延迟”。探测值过期显示“—”，不能视为游戏 RTT 或端到端帧延迟。
- 满员、比赛中、已结算和内容不兼容房间均保留显示；满员/已知不兼容禁用加入。列表人数仅是快照，连接审批仍以房主的实时容量及完整内容签名为准。
- 多网卡响应按本次房间 ID 合并，一键加入使用实际响应的 IP 和房主游戏端口。同机多个房主必须分别使用不同游戏端口，发现端口由广播监听共享。
- 防火墙需允许游戏端口与发现 UDP 47777；本功能不自动修改防火墙。发现失败不会取消已创建房间，仍可通过房间码/IP 连接。
- 地图源表为 `Config/Luban/source/TbMap.xlsx`，模式通过 `mapId` 引用，运行时 `GameplayConfig.Map`；Addressables 配置地址为 `tbmap`，地图场景仍为 `maps/TrainingGround`。旧表名版本的配置摘要不同，不能混连。
- 当前建造、拆除及调参入口见 [积木规则](BlockGameplay.md)；[早期五把武器墨弹与涂色参数核对](../Reports/Archive/2026-09-14/Docs/WeaponAudit/Weapon-Parameter-Audit.md) 仅为历史参数审计。

- Unity 6000.3.9f1；直接打开正式 Boot 场景。人物、枪械、动画和表面资源已正式落地。
- 唯一构建入口仍是 Boot，玩法资源通过本地 Addressables 加载。
- 修改 Config/Luban/source 下角色、武器、房间模式、场地或全局源表后运行 `cmd /c Config\Luban\gen_luban.bat`。禁止手改生成 C#/JSON。
- “喷墨对战/构建/Windows 正式资源版本”只构建现有正式资源，不重新生成地图或人物。
- NGO + Unity Transport，60Hz 玩法模拟/输入采样、30Hz 输入批发/快照和 120Hz 弹道子步。当前源码的玩家快照协议为 37，积木协议为 3；内容签名还包含墨水兼容协议 11、武器模拟版本 33、积木尺寸及边界、Luban 配置、地图拓扑、角色碰撞体、逻辑枪口、相机几何及转身曲线等。不一致时拒绝连接；这些源码常量不单独证明某个发布包已通过握手验收。
- 积木采用 16³ 格稀疏区块，每块边长 1.6 米。地形通过带版本的区块增量和完整快照同步，校验阵营、位置、数量及区块哈希，分片缺失可重传；迟加入及恢复等待初始地形安装完成。0.125 米平面归属网格属于旧涂色系统，不是当前积木精度或计分依据。

## 验证清单

[历史联机验证](../Reports/Archive/2026-09-14/Docs/LAN-Validation.md) 是早期涂色版本的记录，保留其原时间与结果。当前积木玩法的实际验证进展见 [首版状态](../Reports/BlockTerrain/FirstPlayableStatus20261013.md)；下列清单定义需要检查的行为，不表示已通过。Editor、正式 Addressables、独立 Player 与真实双机结果分别记录。

- 同机独立 Player：角色和相机、移动跳跃、射击命中、生成堆积与拆除、普通失支撑下落及守恒、己方积木弦化与材料恢复、击倒救援/重生、完整 180 秒结算、返回热身清空并再次开局。
- 边界场景：错误 IP、端口占用、连接取消、超时、满员、内容不一致、中途加入补同步、退出再加入、房主退出及重复建房。
- 两台实体电脑：客户端通过房主真实 IPv4 地址加入；双方交叉观察角色、积木、击倒与数量比分。真实多机及人工操作观感单列外部验收，不计入当前 Goal；同机测试不能替代这两项。

早期开发版诊断参数为 `-lanSmokeHost` 或 `-lanSmokeClient`，可搭配 `-lanAddress 127.0.0.1 -lanPort 7788 -logFile <绝对日志路径>`。`-lanLeaveAfter 8 -lanCycles 2` 用于两轮退出重进，`-lanCancelAfter 1` 用于连接取消。这些参数和 `[SMOKE]` 的涂色校验值属于原有诊断链路，不能替代当前积木数量、区块哈希与回合恢复验收；图形模式的离屏场景图也不代替正常主相机性能证据。当前后台验收使用已绑定包身份的隔离桌面入口并禁用系统鼠标捕获，不能抢占前台或注入真实键鼠；具体入口以首版状态记录为准。正常游戏不要添加诊断参数。

房间码诊断：客户端添加 `-lanRoomCode <房间码>` 时，使用与中文界面相同的解码及连接入口；此参数与 `-lanSmokeClient` 配合。中文化范围、字体及工程配置见 [工程配置说明](Project-Configuration.md)。

## 热身换队与半自动操作

热身时按 Esc 打开房间菜单，点击“更换队伍”切换到另一队。每队最多四人，目标队有空位且自己存活时可切换；换英雄或换队请求处理期间不能重复操作。成功后保留英雄，在新队出生点补满生命与材料并获得重生保护。热身允许两人同队；正式开局要求双方各至少一人。

支持半自动续射的武器可以点击单发或长按连续射击。长按首发经过起手，后续按武器冷却间隔发射，松开停止续射；单次点击保留冷却末尾缓存，不积压多发。材料不足时，按各武器恢复及攻击条件处理。主动弦化、打开菜单、失焦、输入超时、换英雄和换队会中断攻击，需松开再按。

沿途和脚下建造与主命中共享同一次付费攻击的有限额度，合计最多使用建造预算的 25%；派生效果不额外结算材料或免费产块。实际生成和拆除由房主同步。

对局中按住 Tab 查看粉蓝两队的玩家编号、英雄及 K/D/A，松开关闭。面板不暂停游戏或解锁鼠标。房主按实际伤害统计，最后一击记击杀，击倒前 5 秒内造成过有效伤害的其他队友各记一次助攻。热身不计入战绩，重生保留，返回房间及新局清零；断线重入按新玩家处理。

## 历史参数记录（早期涂色版本）

以下保留旧说明的数值与规则，供追溯早期参数，不能用于当前积木玩法、武器平衡或发布包验收。当前源值以角色表、武器 Asset 及积木规则为准，敌方积木不启用下述敌墨掉血或移速倍率。

100 生命、100 墨量，无友伤。标准射击枪每 6F 发射一颗（参考 60Hz，即 10 发/秒）；人形起手 2F，出墨起手 10F。每发耗墨 0.92，满墨可发射 108 发；近距伤害 36，飞行 8–40F 内线性降至 18。最后一发后锁定回墨 20F，普通/潜墨恢复 10/35 点每秒。

移动/射击/地面潜墨/墙游速度为 5/3.6/8/4 米每秒。地面与空中散布半角为 5°/12°。受伤后等待 1 秒，普通/己方潜墨恢复 30/60HP 每秒。敌墨移速倍率 0.55，每秒扣 20HP，最低扣至 60HP且禁止回血，低于 60HP 不会被环境规则抬高。击倒后 3 秒重生，2 秒保护，开火提前解除保护。时间配置保留参考帧，其他项目初值来自 Luban。
