# TPS 瞄准与发射

玩家准星表示逻辑瞄准射线。开火时由房主用玩家位置、Yaw/Pitch、相机避障结果及逻辑枪口计算路径，不读取动画骨骼、相机震动或客户端上报的命中点。

## 修正距离

`Config/Luban/source/TbGlobal.xlsx` 的 `Global!Q4` 为 `aimCorrectionDistance`，单位米，当前值为 6，必须是有限正数。距离从避障后的逻辑摄像机计算。修改源表后运行 `cmd /c Config\Luban\gen_luban.bat`，不要直接修改生成的 C# 或 JSON。

逻辑相机沿瞄准方向最多探测 100 米，忽略射手自身与 Trigger，并使用最近有效碰撞。交点不超过修正距离时，枪口直指交点；交点更远或没有交点时，先从枪口到达修正点，再沿完整瞄准方向飞行，保留俯仰角。路径在开火时固定。

## 墨弹与遮挡

首段结束且原有直飞期结束之后才开始累计下坠。近距离目标移走或散布导致未命中时，首段结束后继续原发射方向。减速、寿命和伤害衰减仍从开火计时。

散布在两段的各自瞄准坐标系中使用同一个采样偏转，保留霰弹分布，不在修正点重新聚拢。双枪分别使用本次发射的逻辑枪口。

角色到枪口、嵌入障碍的枪口以及实际墨弹飞行都考虑碰撞半径。跨过修正点的模拟步拆成两段扫描，保证墙角和薄墙能够挡弹。目标在枪口后方等退化情况下优先结算近身遮挡，否则沿瞄准方向发射，禁止反向出弹。

`InkShot` 固定保存初始位置/速度、首段路径长度、后段速度和下坠起始弹龄。`InkBallistics.Position(InkShot, ...)` 与 `Velocity(InkShot, ...)` 供权威碰撞、粒子表现、沿途落墨与命中方向共用。旧的直线弹道重载保留用于历史机制测试。

## 准星与联机

相机震动保留在表现层。准星将逻辑交点投影到实际相机画面，没有交点时投影 100 米远点，所以震动时会轻微偏离屏幕中心。命中标记和枪口遮挡提示与准星一起移动。准星不自动补偿弹丸散布或下坠。

玩家协议版本为 11，新弹道字段参与网络序列化；配置和协议版本通过现有连接内容签名校验。旧版本客户端不能与新版本互连。

## 验证入口

- `Splatoon.Tests.TpsAimTests`：近远交点、转折连续性、下坠时机、散布、遮挡、相机投影、序列化及落地距离对比。
- `Splatoon.Tests.TpsAimPlayTests`：在 EditMode 测试入口使用 `EnterPlayMode` 启动真实房主，验证五种武器、GPU 飞行墨弹、移动射击、震动准星、遮挡提示及场景涂墨。运行时需要 GPU，不使用 `-nographics`。
- 本轮结果与截图位于 `Reports/TpsAim/`。落地距离是墨弹首次撞地的位置，不等同于有效伤害射程；相机贴近角色时，较慢墨弹的下坠可能延后，需要结合地图手感验收。
