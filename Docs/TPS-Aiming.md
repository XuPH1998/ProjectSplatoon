# TPS 瞄准与发射

玩家准星表示逻辑瞄准射线。开火时由房主用玩家位置、Yaw/Pitch、相机避障结果及逻辑枪口计算路径，不读取动画骨骼、相机震动或客户端上报的命中点。

## 收敛距离

参数源为 `Config/Luban/source/TbGlobal.xlsx`。`Global!Q4` 的 `aimCorrectionDistance` 是近端收敛距离，默认 6 米；`Global!R4` 的 `aimFarCorrectionDistance` 是无命中时的远端收敛距离，默认 50 米。两者均须为有限正数，远端不得小于近端。距离从避障后的逻辑摄像机计算。修改源表后运行 `cmd /c Config\Luban\gen_luban.bat`，不要直接修改生成的 C# 或 JSON。

逻辑相机沿瞄准方向独立探测最多 100 米，忽略射手自身和普通 Trigger，保留角色命中体，使用最近有效碰撞。远端参数不改变检测范围，也不限制已检测到的交点距离。

设相机位置为 C、单位瞄准方向为 F、枪口为 M，发射目标点为 T：

| 检测结果 | 发射目标点 T |
| --- | --- |
| 交点距离大于近端距离 | 实际交点 |
| 交点距离小于或等于近端距离 | C + F × 近端距离 |
| 100 米内没有交点 | C + F × 远端距离 |

统一以 `normalize(T - M)` 为基准方向，再计算散布。开火后基准方向固定，经过 T 后不再转向。例如 80 米交点仍直接用于计算方向，不会被默认 50 米远端距离截断。

## 墨弹与遮挡

重力只在武器原有直飞期结束后开始累计下坠，当前五种武器均为开火后 10 个参考帧（约 0.167 秒），不等待到达收敛目标点。实际弹丸允许从目标点下方经过，不补偿重力或抬回目标高度。目标移走或散布导致未命中时继续原基准发射方向，同时正常下坠。减速、寿命和伤害衰减仍从开火计时。

普通弹散布只采样一次，霰弹保留原有圆盘分布，过点后不会重新聚拢。双枪分别使用本次发射的逻辑枪口。

角色到枪口、嵌入障碍的枪口以及实际墨弹飞行都考虑碰撞半径，墙角和薄墙仍能挡弹。近距离交点仅决定使用近端收敛点，不代表忽略该障碍；实际弹丸碰到它时照常结算。遮挡提示沿新基准方向检查到实际瞄准点所在的相机深度平面，避免把近处目标后方的障碍误报为挡枪。收敛目标在枪口后方等退化情况下优先结算近身遮挡，否则沿瞄准方向发射，禁止反向出弹。

`InkShot` 保留现有网络字段布局。`FirstSegmentLength` 保存枪口到收敛目标的长度，`PostCorrectionVelocity` 直接等于已经叠加散布的初速，因此过点后方向不变。`GravityStartAge` 保留武器直飞期。`InkBallistics.Position(InkShot, ...)` 与 `Velocity(InkShot, ...)` 供权威碰撞、粒子表现、沿途落墨与命中方向共用。历史分段弹道计算和碰撞扫描能力保留用于兼容与回归测试。

## 准星与联机

相机震动保留在表现层。准星将逻辑交点投影到实际相机画面，没有交点时投影配置的远端点（默认 50 米），所以震动时会轻微偏离屏幕中心。命中标记和枪口遮挡提示与准星一起移动。准星不自动补偿弹丸散布或下坠。

本次不改变玩家协议版本或网络字段布局。新增配置参与现有连接内容签名校验，不同配置版本不能互连。

## 验证入口

- `Splatoon.Tests.GameplayConfigTests`：默认值、有限正数、近远端关系及独立检测距离。
- `Splatoon.Tests.TpsAimTests`：三分支、6 米边界、80 米交点、100 米检测边界、俯仰与枪口、散布、过点方向、下坠时机、遮挡、序列化及落地距离对比。
- `Splatoon.Tests.ShooterMovementTests`：移动射击及带竖直初速、减速、重力的落地结果。
- `Splatoon.Tests.TpsAimPlayTests`：在 EditMode 测试入口使用 `EnterPlayMode` 启动真实房主，验证五种武器、GPU 飞行墨弹、移动射击、震动准星、遮挡提示及场景涂墨。运行时需要 GPU，不使用 `-nographics`。
- 本次结果位于 `Reports/TpsConvergence/`，自动化单房主验证与物理双机验收分别记录。落地距离是墨弹首次撞地的位置，不等同于有效伤害射程；相机避障可以改变基准路径，但不会延后武器的重力起始时间。
