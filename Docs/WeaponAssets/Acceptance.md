## 已覆盖的行为

- 旋转枪 8 帧最短蓄力、119/120/121、149/150 边界、33/66 发、四帧间隔、整轮满蓄伤害、空中/缺墨慢蓄不叠乘、取消退款；30/60/144 Hz 弹道及涂墨所有权一致。
- 首发零散布、双轴同时归零、半进度按一半时间恢复、地空切换保留进度、松手后预付连射继续扩大、末弹后立即恢复、再次蓄力时残余继续恢复、零时长规则、霰弹基础散布、火箭筒蓄力收紧、快照序列化和重放。
- 本机调试 Host、六英雄切换、BOT 添加/清理、无法开始正式比赛、正确签名的远端连接仍被拒绝、普通房入房快照隔离、退出后清理源资产/历史快照缓存。
- 在真实 Host 中修改加载的资产对象：蓄力和连射期间改射速/耗墨/窗口，退回实际预留余额且不重复退款；松开后才能重新开火；散布改动保留进度；在途弹保留旧重力而新弹采用新值；无效参数和模型保留旧版本；合法不同武器模型实际重建装配后恢复原模型。
- 四名权威角色发射 **264 个唯一墨弹**，每人 66 发、总耗墨 35，保留满蓄身份、取消入墨、死亡/重生和枪口握持回归。此处为一个 Host 中的四名权威角色，不能视作四个独立客户端。
