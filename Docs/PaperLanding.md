# 空中弦化落地

空中先跳起再弦化时，纸片保持原有展开高度，移动胶囊的支撑点转换到纸片下方。纸片下降到地面接触范围后，才同时切换 `Grounded`、贴地姿态、地面墨色结算和再次跳跃资格。显示保留原有 0.03 米防穿插间距。

## 实现约定

- `PlayerSnapshot.Position` 在空中纸片形态表示移动支撑点。`AirHumanOffset` 记录原来的人形脚底与支撑点之间的高度差，空中解除弦化时进行逆向转换；落地后从实际地面站起。转换不计入移动速度，不重置跳跃速度。
- 如果原人形位置受到地板或低顶阻挡，沿用 `CompactBody` 延迟站立，直到存在合法站立空间。松开弦化后依然恢复正常重力。
- 移动继续使用原有胶囊；纸片轮廓继续用于受击查询。显示和受击姿态都消费同一模拟结果。空中显示不叠加根节点插值的垂直偏移，避免已经触地时画面仍悬空。
- `CameraRebaseOffset` 抵消支撑点转换当帧的相机跳变，并按模拟时间平滑消退。
- 两个转换字段随快照序列化，预测恢复和重放采用相同状态。快照协议从 19 升到 20，联机双方需要使用新版本。
