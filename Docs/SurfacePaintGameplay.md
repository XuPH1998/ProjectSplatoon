# 地图表面涂色与自由积木（2026-10-18）

本规则取代原来可附着地图表面的实体积木层。自由积木边长保持 0.30 米，每个完整地图色格面积为 0.30×0.30 米（0.09 平方米）。色格没有体积或独立 Collider，角色继续接触原地图几何。

## 普通命中与接触

| 来源与目标 | 结果 |
|---|---|
| 普通积木弹 → 空白地图 | 在地图上涂色，不生成实体附着积木 |
| 普通积木弹 → 敌方地图涂色 | 本次命中直接替换归属，不要求先拆后补 |
| 普通积木弹 → 己方地图涂色 | 直接生成自由积木 |
| 普通积木弹 → 己方自由积木 | 直接生成自由积木 |
| 普通积木弹 → 敌方自由积木 | 按原拆除预算拆除，本次命中结束 |
| 自由积木 → 空白地图 | 该自由块消失，在接触位置涂一个完整色格 |
| 自由积木 → 敌方地图涂色 | 该自由块消失，直接替换接触色格的归属 |
| 自由积木 → 己方地图涂色 | 保留自由块，可以继续运动和堆积 |
| 爆炸 | 按原敌友半径与地图遮挡只拆除，不建造或涂色 |

普通地图涂色保留现有圆盘枚举及每份材料的生成额度。地图真实边界或孔洞放不下完整色格时跳过，不消费该格额度；薄墙正反面独立。精确同平面、同朝向的地图 Collider 共用格目录，跨 Collider 接缝的完整方格仍可涂色，真实孔洞保持空白。

## 计分、资源和表面能力

每个色格计一个存活积木，胜负数量汇总地图色格、自由块及保留的旧表示。普通子弹涂空白或替换敌色各消费一次实际造块额度，按一次实际生成充能；替色不再额外叠加拆敌充能。多弹丸、辅助轨迹和延迟来源沿用原付费预算与事件去重。

自由块转色不再次付款或充能。转空白时，本队自由块减一、色格加一，总数守恒；转敌色时，本队自由块减一、色格加一，同时敌方色格减一。表面归属和自由块删除在通知外部观察者之前完成，网络也使用同一可靠组合提交。

己方地图涂色继续支持恢复、弦化和爬墙，接触位置仍在原地图表面。自由块不提供这些能力。自由块推动参数保持 0.5 kg、静/动摩擦 0.35/0.2、每人共享 100 N 和 3 m/s 上限；玩家 2 米内接近激活，严格超过 2 米的落稳块可停用，运动与空中块继续模拟。

## 实现与验收边界

`BlockSurfaceWorld` 保存独立的面/二维格地址、归属、生命周期和同步版本；`BlockSurfaceGeometry` 从正式地图几何建立完整格目录。显示使用地图表面的分页 Mesh，不创建实体体素层。真实自由块地图接触回调处理转换，睡眠块接触的地图被改成敌色或清空后会被唤醒，再由真实接触转换。

当前生产自由块仍使用 PhysX。专用轴对齐数据模拟的接入和性能门属于 [积木性能重构](BlockSimulationRefactor.md)，不能把本轮表面规则变更或测试通过等同于性能重构完成。每次测试和包身份的实际通过范围记录在对应 Reports 中。
