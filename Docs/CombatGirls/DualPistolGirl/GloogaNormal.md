## 散布规则及近似边界

普通连射采用“前几发较集中，持续射击后偏差增大，停火恢复”。没有实现“越打越集中”或翻滚后的准星合并。

- 地面外锥 3.2°，空中外锥 8°。首发有中心偏置分布，不是严格零偏差。
- 地面偏置从 0.03 起，每成功发射一颗加 0.03，上限 0.25；第九发起使用最大偏置。
- 停火且上一发的射击间隔结束后，以每秒 0.3 恢复；最大偏置到初始偏置需约 0.733 秒，另加当前尚未结束的射击间隔。
- 跳跃偏置 0.4；腾空 25/60 秒后开始向当前地面偏置恢复，70/60 秒结束；落地立即切回地面规则。
- 径向取样为 `U^(log(bias)/log(0.5)) * tan(外锥)`，方位角均匀。偏置是径向切线的中位比例；此算法及 0.25 上限是本项目明确采用的近似，没有声称复现原作随机算法。

三段轨迹参照 [sendou.ink 的参考模拟](https://github.com/Sendouc/sendou.ink/blob/55889eccc7c18f24569098959ae28f4a7034ce4e/app/features/comp-analyzer/core/weapon-range.ts)。三阶段按 60 Hz 参考步计算，步间取线性位置；权威碰撞和飞行显示共用 `InkBallistics` 分派。重力、尺寸换算、TPS 单目标瞄准、即时向下投射的沿途落墨以及现有不规则图集均属于项目适配。没有复刻原作双准星、溅墨子弹飞行、方向性墨迹和墙面滴落。

双枪不再沿用旧的 8.4 米硬性伤害截断，也不以新参考射程截断伤害；远处仍按飞行年龄降伤，撞击或寿命到期时销毁。

## 状态与热更新

地面偏置、腾空年龄、前一刻落地状态及单发锁定偏置均进入玩家快照；枪口序号和双手动作时间线沿用现有同步。新增配置字段全部进入内容签名字节，并提升玩家快照协议及武器模拟内容版本；当前版本以 `PlayerSnapshot.ProtocolVersion` 和 `GameplayContentSignature.WeaponSimulationVersion` 为准。

发射方向、涂墨随机性使用稳定射击身份。涂墨不依赖其他玩家产生的全局弹丸编号。外部按 30/60/144 Hz 调用弹丸模拟时，仍按固定参考步处理碰撞，并在规定距离生成落墨；碰撞段内、命中点之前的落墨不会被丢弃。

同模式参数热更新保留左右枪口及当前散布状态，偏置按新上下限约束。在途墨弹继续使用发射时配置。更换发射/弹道模式沿用既有动作重启规则。

## 验证

运行 `python Tools/CombatGirls/validate_weapon_assets.py --hero 2`，检查当前源表/生成数据/武器资产/Addressables 引用及调参记录。历史迁移记录保持原文件不变，测试在内存中叠加本次调参期望。

EditMode 测试：`Splatoon.Tests.DualPistolGirlTests`。覆盖调参记录、71 发与左右交替、停止条件、出墨起手、地面/空中偏置、随机分布、三段弹道数值、伤害衰减、快照回放、热更新以及真实 Physics/ownership 涂墨。验收容差：换算轨迹 0.00002 米，偏置 0.000001，耗墨余量 0.0002；三个模拟调用频率的涂墨网格哈希完全一致。

Play Mode 测试：`Splatoon.Tests.DualPistolGirlPlayTests`，由 EditMode UnityTest 进入真实 Boot 和本机 Host 房间，验证英雄资源、双枪发射显示、实际玩家伤害、超参考射程命中、墙体遮挡及玩家/场景两种碰撞半径。测试通过也仅代表本机 Host；独立客户端、物理双机、目标设备性能及人工手感仍需单独验收。

可在编辑器空闲且场景无未保存修改时，向 `Temp/DualPistolGirl/tests` 写入两行：报告标签，以及分号分隔的测试类名称。专用验证入口等待现有测试完成，结果写入 `Reports/DualPistolGirl/`。实际执行结果另见 `Validation.md`。
