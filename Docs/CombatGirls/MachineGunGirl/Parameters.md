# 参数与空间适配

现行11.3.0对齐：第一圈2秒，三阶段弹道、逐发偏置和独立脚下／沿途墨调度；下表作为旧实现记录保留。完整实现与最新验收见 [对齐报告](../../WeaponAlignment1130/Report.md)。下文中的旧参数和旧验收证据不代表本轮版本。

采用计划指定的 11.3.0 固定版本，[原始参数文件](https://raw.githubusercontent.com/Leanny/splat3/7280ff9cde8bb1c5dcef46c700c326471584d2e6/data/parameter/1130/weapon/WeaponSpinnerHyper.game__GameParameterTable.json)及 SHA-256 保存在 `Tools/ValidationData/MachineGun/`。这些参数用于本项目实现，不作为完整复刻原作内部算法的证明。

| 项目 | 实现 |
|---|---|
| 最短有效蓄力 | 8 帧；提前松开的请求等到该边界 |
| 第一圈 / 满蓄 | 120 / 150 帧 |
| 连射 | 间隔 4 帧；33 / 66 发，包含首弹和末弹 |
| 射击窗口 | 第一圈 130 帧、满蓄 260 帧；实际末弹分别在释放后 128 / 260 帧 |
| 恢复 / 回墨锁定 | 末弹后 4 / 40 帧 |
| 伤害 | 未满蓄 32、满蓄 40，飞行第 11–19 帧下降到 16 |
| 墨量 | 每颗结算 `35/66`；第一圈 17.5、满蓄 35 |
| 慢蓄 | 空中或可用墨不足时为 1/3 速度，两个条件不叠乘 |
| 普通 / 友方潜墨移速 | 4.583333 / 7.2 米每秒 |
| 蓄力 / 持续射击移速 | 2.291667 / 3.125 米每秒 |
| 蓄力起跳 | 约 2.696 米每秒；持续射击恢复普通跳跃 |

部分蓄力分段计算：8–120 帧将射击窗口从 0 增加到 130，120–150 帧从 130 增加到 260；弹数为 `floor(窗口 / 4) + 1`。不能用整体蓄力百分比乘 66。满蓄身份在释放时锁定，后续弹丸各自根据当前瞄准方向发射。

墨罐可用量和预留量分开。蓄力逐步划出预留，释放时把不足一颗的零头退回墨罐；发射从预留扣除。缺墨时慢速充填只补足预留的缺额，普通回墨关闭；取消将未发射预留转回可用量，重复取消不重复返还。此补充模型按本轮批准的预留与慢蓄方案实现，未宣称通过原作逐帧耗墨视频比对。

空间标尺固定为 `18 / 24.037 ≈ 0.748846`。位置与半径乘该比例，速度同时乘 60，加速度同时乘 3600；帧数保持不变。步行与潜墨使用计划指定的相对限制，独立于弹道标尺。

本轮弹道与涂墨采用以下项目适配：

- 初速中心随第一圈从原始距离单位 1.05 增加到 2.4；速度区间以 2.4 ± 0.14 换算，并采用向中心偏置的对称随机采样。最大散布地面水平 3°、垂直 2°，空中双轴 6°。动态进度同时作用于双轴：完全恢复为 0，释放连射后默认 1 秒扩大、停止后 0.5 秒完全恢复；蓄力不增长。原作参数文件不包含完整继承值和引擎采样算法，因此不将本项目的幂分布、随机区间解释等同于原版实现。
- 直进 8 帧，随后使用项目的 8 帧线性减速到 10% 和下坠模型；重力以 0.016 距离单位/帧²换算。这是明确的弹道适配，未完成原版 `GoStraightStateEndMaxSpeed` 等内部阶段的逐帧复刻。
- 世界 / 玩家扫掠半径分别为 `0.2 / 0.225 × 标尺`；第一圈结束后伤害距离上限不再增长。
- 每八发一次脚下落墨；每弹最多一次沿途落墨，半径与间距独立于步枪。落点使用项目已有的不规则墨迹图集，保留半径换算，未新增原版纵深椭圆、墙面滴落等专用形状算法。
- 每颗旋转枪弹的墨迹图案由稳定发射数据确定，避免 30/60/144 Hz 外层调用分批顺序改变覆盖。原有五名英雄的图案选择逻辑保持原样。

实际涂地结果来自生产弹道、Physics 扫掠与 0.125 米所有权网格；详情见 `Evidence/Ballistics/*.json` 与逐弹轨迹 CSV。测量采用正式枪口和相机参数，固定随机种子；不是 HUD 距离字段的推算，也不是原作原始录像验收。
