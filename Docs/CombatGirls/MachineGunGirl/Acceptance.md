# 验收记录

环境：Windows，Unity 6000.3.9f1，URP 17.3.0，UTS 0.14.1-preview，RTX 3060。使用独立验证工程执行 Unity 编译、资源构建和 Play Mode，产物同步回当前工程。源 CombatGirls 工程没有被 Unity 打开或写入。

**静态与配置检查通过。** 对照 278 个源文件哈希；10 个 FBX / 11 个正式动画片段；Humanoid 有效且 Hips=pelvis；正式角色无 Missing Script；保留 SDF 及脸部方向绑定；角色、武器和弦化资源引用完整。Luban 源表与生成结果共检查 540 个值，前五名英雄的原有字段值一致，Assets 无重复 GUID。详见 `Evidence/static-validation.json`。

**定向 Unity 验证：67 项通过，0 失败。** 包括最短点按、119/120/121 与 149/150 帧边界、33/66 发及四帧间隔、保持满蓄、满蓄伤害身份、重复取消、低墨与空中慢蓄、射后恢复边界、快照序列化和重放、实际移动/跳跃速度、跨调用频率的弹道与涂墨一致性、六名英雄资源服务及弦化接触回归。原始结果见 `Evidence/tests.xml`。

**已执行真实房主 Play Mode。** 从 Boot 和 Addressables 编辑器模式启动，正常选择 ID 6，添加三个继承 ID 6 的 BOT。四名权威角色各发射 66 颗，累计 264 个独立弹丸 ID；每轮总耗墨约 35；验证 -65°、-45°、0°、35°、75° 俯仰下的左手握点、潜墨取消、潜墨中死亡、重生与武器挂点恢复。BOT 是服务器角色，不代表三个独立网络客户端。逐帧数据和截图见 `Evidence/PlayMode/`。

**视觉证据。** `Evidence/Screenshots/` 包含源/目标同姿态、同白色主光、同相机、800×800 的正侧背面和脸部，以及两种死亡末帧。训练场截图为 960×960，使用现有 URP Renderer 和墨迹系统。正式材质仅启用 `_Is_Filter_LightColor=1`，详细记录见 `Evidence/asset-validation.txt`。没有用截图相似度替代运行时握点检查。

**性能记录。** `Evidence/PlayMode/four-model-performance.csv` 对比相同摄像机与 960×960 输出下四个 RifleGirl 和四个 MachineGunGirl 的射击模型。各预热 40 帧并采样 120 帧，完整六英雄资源均保持加载；记录帧时、Draw Calls、Batches 与已分配内存。该比较包含编辑器开销，排除网络传输和弹丸模拟；四人权威齐射的同步 CPU 时间和在途弹数另记于 `results.txt`，不能合称正式四人对战性能。

**扩大回归没有全绿。** 初轮扩大到 189 项，177 项通过，12 项失败。其中一项是旧协议版本 17 的断言，已更新为 18 并重新通过。其余 11 个失败用例在迁移前提交 `63fbb1b` 的独立 worktree 中复现：9 项旧步枪数值/回墨断言、1 项瞄准浮点精度断言、1 项完整回合 UI 用例。前 10 项失败内容一致；完整回合用例在基线停在出生保护断言，本次停在 batchmode 的鼠标锁定断言，失败位置不同，未标记通过。未回退现有武器参数，也未削弱这些旧断言。详情见 `Evidence/regression-comparison.json` 及两份 XML。

**尚未执行的专项验收：** 独立客户端的晚加入、重连和延迟/丢包场景；真实双机；正式 Addressables 内容构建；发布包；目标设备的完整四人战斗性能；原作同版本完整弹道/耗墨逐帧比对。快照自动测试与本机房主测试不替代这些项目。现有完整回合交互用例存在上述基线失败。
