# 角色三视图 · 喷3式比例

最终交付 6 套独立三视图，每张 1536 × 1024 PNG，从左到右为正面、朝左的侧面、背面。

保留现有角色的主要发型、头饰与服装配色，以大头、窄肩、短躯干和厚底大鞋统一造型。正面头部摆正、双眼水平；侧面采用正侧视构图，双脚平行且前后齐平，远侧腿脚遮挡在近侧后方。

这些图片由内置 image_gen 生成并修订，供建模造型参考；它们不是从同一个三维网格输出的真实正交投影。建模时需统一三面尺寸、关节位置及非对称配件，头身比为美术目标而非测量保证。
