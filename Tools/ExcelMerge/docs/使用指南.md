# ExcelCompare 使用指南

Excel 三方合并工具，用于解决 Git 中 `.xlsx` 文件的合并冲突。

---

## 什么时候需要用？

当你在 Git 上合并分支（merge）时，如果两个人同时修改了同一个 `.xlsx` 文件，Git 无法自动合并，就会产生冲突。这时候就需要用 ExcelCompare 来帮你把两边的修改合到一起。

---

## 环境要求

- **Python 3.10 或以上版本**（[下载地址](https://www.python.org/downloads/)）
- 首次运行脚本时会自动安装所需的 Python 依赖（openpyxl、flask、click），无需手动操作

> 脚本会自动查找系统中的 Python，支持：py launcher、PATH 中的 python、miniconda、anaconda、Windows 标准安装路径。如果你已经安装了 Python 但提示找不到，请确认 Python 已加入系统 PATH。

---

## 快速开始

### 第一步：打开工具

在项目根目录（design 文件夹）下，双击运行：

- **Windows**：`excel-merge.bat`
- **Mac/Linux**：终端运行 `./excel-merge.sh`

脚本会自动扫描所有冲突的 Excel 文件，逐个打开合并界面。

> 如果只想处理某个文件，可以在命令行指定：
> ```
> excel-merge.bat source/Datas/map.xlsx
> ```

### 第二步：在浏览器中解决冲突

运行后会自动打开浏览器，进入合并界面。

### 第三步：保存

解决完所有冲突后，点击右上角的 **「保存合并结果」**，文件会自动保存并标记为已解决。

## 界面介绍

### 顶部栏

| 按钮 | 作用 |
|---|---|
| **撤销** | 撤回上一步操作（可多次撤销） |
| **全部选择 Ours** | 所有冲突都选"我的版本" |
| **全部选择 Theirs** | 所有冲突都选"对方的版本" |
| **查看增量** | 分别查看两个分支各自改了什么（对比 Base） |
| **保存合并结果** | 保存最终的合并文件 |
| **取消** | 放弃合并，不保存任何修改 |

顶部还会显示当前的冲突解决进度，例如 `已解决 3/5 (20 总计)`。

### Sheet 标签页

如果 Excel 有多个 Sheet，会在顶部显示标签页。标签上的数字表示该 Sheet 中有多少处变化。点击切换不同的 Sheet。

### 主表格区域

表格中用颜色标记不同状态的单元格：

| 颜色 | 含义 |
|---|---|
| 绿色背景 | 只有"我"改了（Ours Only） |
| 蓝色背景 | 只有"对方"改了（Theirs Only） |
| 红色虚线边框 | 双方都改了，且改的不一样（冲突） |
| 浅灰色 | 双方都改了，但改成了一样的值（无需处理） |

**已解决的单元格**会在左上角显示一个小标记：
- 绿色小角标 = 选了 Ours
- 蓝色小角标 = 选了 Theirs
- 紫色小角标 = 保留双方
- 橙色小角标 = 手动编辑的值

### 对齐列

在表格上方有一个 **「对齐列」** 下拉框。

这个功能用于处理"插入行"的情况。当两边都新增了行时，工具需要知道用哪一列作为"主键"来对齐数据行（类似数据库的 ID 列）。工具会自动检测，但如果对齐不正确，可以手动选择后点 **「应用」**。

---

## 解决冲突

### 单个单元格

1. 点击有颜色标记的单元格
2. 右侧会弹出详情面板，显示三个版本的值：
   - **Base**：合并前的公共版本
   - **Ours**：我的修改
   - **Theirs**：对方的修改
3. 选择一个操作：

| 按钮 | 作用 |
|---|---|
| **Accept Ours** | 采用我的值 |
| **Accept Theirs** | 采用对方的值 |
| **保留双方** | 两行都保留（我的在上，对方的在下） |
| **手动编辑** | 自己输入一个值（支持公式，如 `=SUM(A1:A5)`） |

### 整行操作

选中某个单元格后，详情面板下方会出现整行/整列操作按钮：

| 按钮 | 作用 |
|---|---|
| **整行选 Ours** | 这一行所有冲突都选我的 |
| **整行选 Theirs** | 这一行所有冲突都选对方的 |
| **删除此行** | 删除这一行（仅对新增的行有效，已有行会保持原值） |

### 整列操作

| 按钮 | 作用 |
|---|---|
| **整列选 Ours** | 这一列所有冲突都选我的 |
| **整列选 Theirs** | 这一列所有冲突都选对方的 |
| **删除此列** | 删除这一列（仅对新增的列有效，已有列会保持原值） |

### 全部批量操作

如果冲突很多但你确定要全部选某一方，可以直接点顶部的：
- **全部选择 Ours**：所有 Sheet 的所有冲突都选我的
- **全部选择 Theirs**：所有 Sheet 的所有冲突都选对方的

---

## 查看增量对比

点击顶部的 **「查看增量」** 按钮，会弹出一个对比窗口，分左右两栏：

- **左栏 (Ours vs Base)**：显示"我"相对于公共版本改了什么
- **右栏 (Theirs vs Base)**：显示"对方"相对于公共版本改了什么

这样可以清楚地看到每一方各自做了哪些修改，帮助你做出更好的合并决策。

点击 **「关闭」** 回到主界面。

---

## 撤销操作

做错了？点顶部的 **「撤销」** 按钮可以回退上一步操作。支持多次撤销。按钮上会提示即将撤销的是什么操作。

---

## 保存与退出

- **保存合并结果**：点击后会将合并后的文件写入磁盘。如果还有未解决的冲突，会提示剩余数量，但仍然可以保存。
- **取消**：放弃本次合并，不做任何修改。会弹出确认对话框防止误操作。

保存成功后，窗口会在 1.5 秒后自动关闭，工具会自动处理下一个冲突文件（如果有的话）。

## 常见问题

### Q：打开后显示"没有发现冲突的 xlsx 文件"
说明当前 Git 仓库中没有处于冲突状态的 Excel 文件。请确认：
1. 你已经执行了 `git merge` 或 `git pull` 并产生了冲突
2. 你在正确的仓库目录下运行脚本

### Q：表格中行的顺序看起来不对
尝试修改 **「对齐列」**，选择数据的 ID 列（通常是第二列），然后点 **「应用」**。工具会按新的主键重新对齐行。

### Q：保留双方会发生什么？
选择"保留双方"后，合并结果中会包含两行：我的数据在上面一行，对方的数据在下面一行。

### Q：删除行/列后数据会丢失吗？
- 删除**新增的**行/列：该行/列会从最终结果中移除，后续行列自动紧凑排列
- 删除**已有的**行/列：不会丢失数据，会保持原始值不变

### Q：可以同时在多台电脑上运行吗？
可以。每次运行会使用一个随机端口，互不影响。
